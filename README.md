# Cleany — versiones

Instaladores de **Cleany**, una app personal de limpieza para macOS. El código no está en este repositorio.

- Descarga la última versión en [Releases](../../releases/latest).
- `appcast.xml` es la lista de versiones que consulta la app para actualizarse sola (Sparkle).

Requiere macOS 15 o posterior.
